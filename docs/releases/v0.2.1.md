# v0.2.1 — 工业数据智能分析系统功能发布

发布日期：2026-10-14。

面向工业数据查询与故障分析，发布自然语言问数、知识检索、SQL/Python 分析、工业看板和可追溯报告。功能说明按“工业数据智能分析系统”组织，并以当前源码已实现能力为准。

## 本次发布内容

1. **Agent 编排与连续分析**：自研异步 GraphEngine 编排意图识别、Schema/知识召回、任务规划和 SQL/Python 执行。支持多轮上下文、人工审核、持久化 checkpoint 和审核中断恢复；通过 REST/SSE 与 18 个 MCP 工具提供分析与任务入口。
2. **RAG 与数据库上下文**：采集表结构与关联信息，结合业务知识为 SQL 和分析提供上下文。支持关键词与向量检索、RRF 融合，以及可选本地 BGE-M3、Elasticsearch/Milvus。Embedding 配置重建成功后切换，防止索引与模型不匹配。
3. **SQL 生成与有限纠错**：结合 Schema 与业务口径生成 SQL，使用 SQLGlot AST 校验只读语句，并进行语义检查。字段、语法或执行异常反馈给模型修正，受重试次数与时间预算限制。
4. **工业指标、图表与分析**：按设备、型号、故障类型与窗口组织查询和图表；Python 分析在受限 Docker 沙箱执行。PdM 与 Scania 分别管理指标、数据粒度与来源语义，匿名特征和相对时间不冒充物理定义或日历时间。
5. **证据化报告与受控诊断**：报告引用已执行结果与知识来源，关键数值由程序读取或重算，明确筛选范围、并列项、截断、NULL 和指标版本。诊断检查观察条件，保留统计关联与工程根因确认之间的边界。
6. **周期报告与行动复核**：日/周/月计划按时区和固定指标定义生成上一完整周期，核对数据日期水位并避免重复运行。行动关闭要求同口径、同范围且窗口合规的新实测证据与负责人复核。调度默认关闭，需要显式启用。

## 0.2.1 报告体系修正

- 补齐实时看板日期水位接口和真实服务回归，支持周期报告判断数据范围。
- 报告使用实际已保存的查询范围；原始文本惰性显示，数值与方法结论通过受控证据协议。
- 版本化指标统一粒度、分子/分母、单位、空值与排除规则。故障设备占比以同范围去重设备数计算，零分母返回 NULL。
- 受控诊断不会把汇总缺字段、重复观察或匿名特征推断成已确认因果。
- 保留独立验收脚本、失败证据、预览隔离与回退工具。

## 本次上传与验证

发布源码基于本地版本 0.2.1，来源提交 `a603377`。保留源代码、前端、测试、演示生成工具、许可与架构文档；本次补充功能 README、通用配置示例与发布说明。

仅上传版本控制中的源码范围，不包含 `.env`、虚拟环境、模型权重、上传文件、管理数据库、原始工业数据、运行日志或私有备份。原始本地项目和运行环境保持原样。

本次现有后端全量离线回归 **379 passed，0 failed / 0 errors / 0 skipped**，耗时 134.02 秒。测试覆盖 mock、接口合同与确定性逻辑；本轮未重测真实模型、外部数据库、GPU BGE、Docker 沙箱或 MCP HTTP 网络传输。

前端 **67 项单元测试通过**，生产构建成功。发布副本的示例配置、临时数据库接口烟测、BI Compose 路径插值及 PowerShell 脚本解析通过。配置检查同时修正 `CORS_ORIGINS` 的 JSON 列表格式，避免新环境启动时解析失败；Redis 与本地 GPU Embedding 改为可选配置，Scania 挂载路径由部署者提供。

`/echo/ok` 与 `/health` 返回 HTTP 200；测试机的 Docker socket 不可用，整体健康状态如实返回 `degraded`。前端构建存在已有的依赖弃用与大 chunk 警告。上述检查不代表 Docker/GPU 和真实模型部署已全部就绪。

## 使用边界

- 当前工作流是自研 GraphEngine，尚未迁移至 LangGraph。
- 本次未重新运行 Top-5 93% 和 SQL EX 97% 的模型评测，未将这两个数字作为发布成绩。
- 聊天附件功能已实现，指定 Pandas 方法与图表业务粒度的完整真实模型验收仍未通过。
- 统计关联、候选原因与行动指标达成不构成工程根因或干预收益的因果证明。
- 预测/RUL、真实 OEE/FPY/MTTR、邮件推送和独立身份认证不在当前实现范围内。
- Docker/GPU、真实模型、外部数据库、向量服务与完整工业数据的可用性取决于部署环境；离线回归不能替代这些集成验证。
