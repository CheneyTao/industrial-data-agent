# DataAgent Python 报告体系改进与回退

此版本在现有 Python 项目上增加证据报告、统一指标、受控诊断、业务验收和周期行动管理。旧服务和旧数据保留，新版本先在独立预览环境运行。目标是让报告的数字、使用条件和后续行动可核查，而不是把统计关联写成已确认根因。

## 每项改进及使用条件

### 报告中的事实声明

模型只选择已保存结果的行、字段、最大值或最小值操作，以及受控计算的方法声明。数值由程序读取或重算，报告协议没有供模型填写数值、原因断言或算法名称的自由文本字段。未知证据、越界坐标、没有成功执行记录的结果和无法重算的计算不会发布；被拒绝的声明及错误原因保留在证据目录。

排名注明返回行范围、保留全部并列项；截断结果不升级为全局排名。NULL 与零分开显示，零基数变化率保持不可用。计算列名按实际字段与操作生成，模型不能把“已确认根因”等任意文字作为可信计算标题。原始字段和单元格文本保持惰性显示，不能作为脚本或 Markdown 图片执行。

已注册 BI 指标保留口径版本。普通 SQL 的输出只核验单元格一致性，不自动认证其业务语义；没有物理表来源的常量查询会明确标注。Python 的静态导入不证明实际调用了算法，尚未转化为受控计算的 Python 输出不作为已核验的方法或数值结论。

正文还展示已保存的数据集和真实执行日期、设备、型号等筛选；执行登记范围优先于备用元数据，不从问题或模型猜测。相对时间明确不是日历时间；缺少结构化范围的 SQL 报告要求查看实际执行 SQL 和参数，不写成全厂或全量。

相关实现：`report_claims.py`、`reports.py`、`calculations.py`。报告表达更受约束；需要新的统计结论时，应增加可检验的受控操作和模板，而不能重新开放无约束事实写作。

### 看板和分析的指标口径

PdM 七项指标及 Scania 注册指标补齐版本、粒度、单位、分子和分母、排除条件、时间窗口、空值规则、归属和实际结果列绑定。公式或版本变化会改变语义指纹；定义列表排序不改变指纹。查询、BI 看板和报告携带同源口径。旧 PdM 概览及按型号接口也使用同一故障设备占比计算。

故障设备占比是筛选期至少发生一次故障的去重设备数除以同范围设备数，不是故障次数除以设备数，也不是预测概率。设备分母为零时返回 NULL，不再返回 0%。缺少绑定列会停止计算；排名多取一行以准确标识截断。

Scania 车辆粒度与观测行粒度分开，训练、验证、测试分区不混用，删失记录与维修标记保留来源语义。匿名相对时间不转换成真实小时；原始散点观测不冒充均值聚合。语义指纹证明定义一致性，不证明数据新鲜度或因果正确性。

相关实现：`bi/contracts.py`、`bi/metric_registry.py`、`bi/catalog.py`、`bi/scania.py`、`dashboard.py`。

### 受控诊断

诊断只接受当前智能体拥有的成功 SQL 或 BI 查询结果。计算前检查结果完整性、重复观察键、空值、二元事件定义、设备标识和窗口；指定了事件先后时间时检查其方向。混杂候选字段和现场资料不足会列入缺失输入。

符合条件时计算暴露组和未暴露组的观测风险差、相对风险；独立观察单元条件满足时给出观测比例差区间，同设备重复观察不套用独立行区间。本版本最多输出“统计关联”，不会自动升为模型归因、假设成立下的因果或工程确认。匿名 Scania 特征的物理根因确认请求会被拒绝。

入口是“报告与诊断”的“受控诊断”页签；接口为 `POST /api/diagnostics`。输入运行编号、结果证据编号及真实字段。缺字段时应重新查询，不能填造一个数据结果。

### 独立业务验收

新增独立验收脚本，标准答案不进入模型提示。检查完整并列极值、返回行范围、非空计数与去重计数、零基数变化率；每轮保留完整证据。验收直接比较结构化坐标和值，不以某个关键词是否出现为通过依据。

默认模式测试确定性合同及算术，不代表模型理解能力。`--live` 才调用当前配置的模型，其中极值选择和范围检查验证模型选择，其余检查验证受控计算。运行方式：

```powershell
.venv\Scripts\python.exe -m tools.evaluate_report_release --output work/report-v020/acceptance --trials 5
```

结果保存在 `acceptance.json`。这是一套最小回归基准，不代表已覆盖全部工业业务或证明现场根因。

### 周期报告和行动闭环

周期报告复用原 BI 图与任务管理，没有另建分析智能体。日、周、月周期按指定时区生成完整的上一周期；固定指标定义和指纹，核对来源日期水位后执行。相同计划、周期与定义只建立一个运行；支持暂停、人工触发历史周期、超时和有限重试。

后台调度默认关闭，预览环境显式开启。状态页显示调度是否运行。普通查看不推进重试；“核查并推进”是显式操作。不确定的调度启动或失去心跳不会盲目自动重试，需核对旧任务状态，以免并发重复执行。只有来源有日历日期水位的数据集可以按日历调度；Scania 相对时间不冒充日历周期。

行动记录包含负责人、截止日、基线证据、目标和验收条件。关闭行动必须提供新的实测证据并由记录的负责人复核；指标定义、数据集、设备筛选和维度必须一致，前后窗口须完整、等长且实测窗口晚于基线且不重叠。缩小设备范围或周期不能用来伪造达标。目标达成仍不是干预收益的因果证明，负责人姓名是智能体凭据下的声明，尚非独立身份认证。

新增管理表仅为 `report_schedule_v1`、`report_run_v1`、`report_action_v1`，不删除或更改原有表。日期水位是观测范围，不保证每张源表全量、完整或事务快照一致。

### 新界面和版本可见性

新增“报告与诊断”导航，包含指标字典、受控诊断、周期报告及行动复核。智能体切换会清除内存密钥、取消请求并丢弃迟到响应；界面不持久化输入密钥。报告正文使用已有清洗渲染，原始证据可展开查看。

健康接口和新分析证据包含软件版本与构建提交，方便区分当前源代码和正在运行的镜像。原来已运行的旧镜像不会因为源码变化而自动升级。

## 本机验收与记录

后端全量测试、前端 67 项测试和生产构建均通过；独立确定性合同验收 5 轮、20 项通过。该合同验收不是模型理解能力的替代。另使用真实配置模型完成 BI 报告和历史月报端到端验收，并确认重复触发同一月报仍为同一运行、同一任务和一次尝试。

历史月报的 2015 年 1 月故障次数为 94。受控诊断对缺少 exposure/outcome 的汇总证据返回 blocked 和缺失输入，没有输出因果结论。行动闭环使用 1 月与 3 月两个 31 天、同设备范围的历史查询，仅作功能样例：错误负责人复核被拒绝，实际证据通过后才能关闭，不代表实施了维修或确认收益。

本机验收材料保存在 `work/report-v020`：`acceptance/acceptance.json`、`live-report-result.json`、`live-scheduled-report-v021.json`、`live-diagnostics-gate.json` 和 `live-action-v021.json`。这两个验收报告计划已暂停，不会持续执行。旧管理库仍为 17 表，独立预览库为 20 表；旧界面和新界面均可访问。源码基线已实际恢复到同级独立目录，停止和重启预览也已演练。

## 退回和恢复

旧版本服务保留在端口 3000、8065 和 8066。停止新预览后，继续打开旧界面即可；停止不删除新报告、数据库或证据。

回退脚本按精确容器名称和版本标签核对后停止；前端按进程编号、脚本路径和创建时间核对，不误停其他 Node 进程。重新启动已有容器还会核对隔离数据库、Redis 命名空间及证据和上传目录。前端占用端口未释放时明确报错，不报告虚假的成功。

```powershell
pwsh -File tools/report_version.ps1 -Action StopPreview
```

若需要旧源码，以下命令在同级新建 `DataAgent-Python-baseline-20261013`，不会覆盖当前改进源码或用户数据。目标目录已存在时会停止。

```powershell
pwsh -File tools/report_version.ps1 -Action RestoreBaselineSource
```

重新启动预览：

```powershell
pwsh -File tools/report_version.ps1 -Service backend
pwsh -File tools/report_version.ps1 -Service mcp
pwsh -File tools/report_version.ps1 -Service frontend -Build
```

预览管理库来自改进前备份，之后新旧环境中的会话和设置各自变化，不自动同步。不要把旧库备份覆盖当前生产库；只有确实需要数据恢复时，才在停服、再次备份和确认目标后恢复到新数据库。

## 明确保留的能力边界

本次没有安装可能冲突的 DoWhy 或 PyRCA 依赖，也没有声称完成这些框架的因果识别、效应估计或反证集成。预测模型、RUL、真实 OEE、FPY 和 MTTR 尚需相应训练数据、生产质量字段或维修结束时间。遥测观测时长除以故障事件数仍是代理指标，不是已确认的真实运行时长 MTBF。邮件推送、人员身份认证、跨团队审批及生产流数据快照不在本次实现范围内。
